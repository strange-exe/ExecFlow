Run Python online in your browser

CodeEditor runs real Python, the CPython interpreter compiled to WebAssembly, inside your browser tab. There is nothing to install and no account to make. A program that calls input() waits for you to type, and when it fails, the error comes with an explanation in plain words.

Your first program

  1. Open the editor and make a file whose name ends in .py.
  2. Write your program and press Run. The first run in a browser downloads Python; after that it starts from the browser's copy.
  3. When the program calls input(), a field appears in Output beside the prompt: type your answer and press Enter. You can also type the lines into the Input box before you run.
  4. If it stops with an error, the line is marked in the code and the explanation sits under the error. The Flowchart tab draws how the program runs; the flowchart guide explains it.

An error, explained

A mistake almost every beginner makes: input() returns text, and + can't join text to a number. Python's message is correct but terse; under it, CodeEditor says what it means for this line and how to fix it.

IndentationError: a block with nothing in it

In Python the indentation is the block: the lines under an if, a loop or a function must be indented further than it. Here the print was meant to belong to the if, so nothing runs at all; the message names the line that should have been indented.

NameError: a name spelled two ways

A name has to be given a value before a line uses it, spelled exactly the same. Python itself suggests the name it does know; the explanation says what to check.

Which Python is this?

The same check you would run on your own computer. The platform is emscripten, the toolchain that compiles Python to WebAssembly, not your operating system.

What loads, and when

  • Python itself (Pyodide 314.0.7: the interpreter and the standard library, about 13.5 MB) downloads the first time CodeEditor starts Python, and the site's service worker keeps it, so later visits start without downloading it again.
  • numpy 2.4.6 and pandas 3.0.2, with what pandas needs (python-dateutil, pytz and six), download only when a program imports them, then stay in the browser. numpy is about 3 MB and pandas about 4.2 MB.
  • CodeEditor sees these imports in the program's own lines (import numpy, from pandas import ...). An import made through importlib or __import__ can't be seen ahead of time, and fails with a note saying so.
  • A Python program can use up to 512 MB of memory.

Time and output limits

Questions

Is it real Python, or a subset?

It is CPython 3.14.2, the reference Python interpreter, compiled to WebAssembly by the Pyodide project, with its standard library. What differs is the machine around it: no network, no threads and no windows, as above.

Does it work offline?

Yes, after the first visit. The editor and Python are kept by the site's service worker, so they open and run without a connection, including programs that wait for input. numpy and pandas work offline once a program has imported them.

Do I need to sign up?

No. There are no accounts. Your files are kept in your browser; you can also connect your own GitHub account to sync them to a private repository.

Is my code sent to a server to run?

No. It runs in your browser. When you share a program as a code link, the code travels inside the link, after the #code= mark. Browsers never send that part of an address to a server, so the link works without the code being stored anywhere. Read the privacy page for everything CodeEditor keeps and sends.

Why is the first run slower?

The first run in a browser downloads Python (about 13.5 MB). Later runs start from the browser's copy. The first import of numpy or pandas downloads that package the same way.
