02 / features

Everything around the graph works without setup.

No installer, no account, no waiting for a server. These are the parts that make ExecFlow easy to keep using.

  1. node 01

    Runs on your own device

    Python runs through Pyodide as soon as you open a file; programs that ask for input wait for you to type it, and numpy and pandas download the first time you import them. C and C++ compile in the browser with clang built for WebAssembly, after a one-time download, with errors marked on their lines and explained in plain words. Nothing to install, and it keeps working offline.

  2. node 02

    Share code as a link

    Send one file or a whole folder as a short link. The code can travel inside the link, so anyone can open it in ExecFlow with no account. Or link the file in your repository, or make a secret gist anyone with the link can open.

  3. node 03

    GitHub sync, if you want it

    Your files are kept in your browser first, and nothing leaves it unless you connect GitHub or share a link. Sign in with GitHub and your changes sync to your own private repository, each commit named after its files. What ExecFlow keeps and sends

  4. node 04

    40+ colour themes. Works on phones.

    Pick a look you can stare at for an hour. The same editor, flowchart included, works on a phone screen, with Run in reach of your thumb.

    See how your code runs

    Open a file and its flowchart is drawn on a board beside the code. Every decision, loop and early return becomes a box, in the standard flowchart shapes. Click a box to jump to its lines, or read the same steps as a list.

    It helps with code you wrote and code you were given to read. Export the chart as a PNG or SVG for a report or an assignment. Capture makes a picture of the lines you select, ready to share.

    On a phone, a Code and Flowchart switch sits under the top bar, and Run waits in the dock at the bottom, in reach of your thumb.
