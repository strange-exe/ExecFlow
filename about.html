A flowchart in 3D: a start, a step, a decision with a loop back, an output and an end, the shapes ExecFlow draws for your code.

See how your code runs

Open a file and its flowchart is drawn on a board beside the code. Every decision, loop and early return becomes a box, in the standard flowchart shapes. Click a box to jump to its lines, or read the same steps as a list.

It helps with code you wrote and code you were given to read. Export the chart as a PNG or SVG for a report or an assignment. Capture makes a picture of the lines you select, ready to share.

On a phone, a Code and Flowchart switch sits under the top bar, and Run waits in the dock at the bottom, in reach of your thumb.

Nothing to install

Python
name = input("Your name: ")

    print(f"Hello, {name}! Line {i + 1}")
Runs as soon as you open a file. Programs that ask for input wait for you to type it. numpy and pandas download the first time you import them.
C
Compiled in the browser after a one-time download, with errors marked on their lines.
C++
The same compiler and download, with the C++ standard library.

Common errors come with an explanation in plain words, next to the line they point to.

Your files, your repository

  • On this computer first. Files are kept in your browser. Nothing leaves it unless you connect GitHub or share a link.
  • In your private GitHub repository. Sign in with GitHub and your changes sync to it, each commit named after its files.
  • Shared with one link. The code can travel inside the link, so anyone can open it in ExecFlow with no account. Or link the file in your repository, or make a secret gist anyone with the link can open.
