Run C++ online in your browser

CodeEditor builds your C++ program with clang and the libc++ standard library, then runs it in your browser tab. std::cin waits for you to type, vector, string and the algorithms are there, and the errors students meet most are explained in plain words.

Getting started

  1. Open the editor and make a file whose name ends in .cpp.
  2. The first time, Output offers the compiler as a one-time download, the same one C uses. In CodeEditor's words: “”
  3. Press Run. CodeEditor builds the program and runs it; the run log shows how long each took.
  4. When the program reads std::cin, type into the field in Output and press Enter, or put the input in the Input box before you run.

Input with cin and getline

std::cin >> year reads one word or number; a name with a space in it needs std::getline, which reads the whole line. Read the line first: after cin >>, the end of that line is still waiting, and a getline straight after it would read an empty line.

vector and sort

A std::vector grows as you push_back; std::sort from <algorithm> puts it in order, so the best score ends up at the back(). The range-based for walks every element without an index.

Working with string

A std::string knows its length, can be built backwards from its reverse iterators, and find returns std::string::npos when a character isn't there.

The error everyone meets once: cout without std::

cout and endl live in the std namespace. clang even suggests the fix; CodeEditor says why it is needed and the two ways to write it.

no matching function: the wrong number of values

greet takes a name and an age, and the call gives only the name. clang's message says no version of the function fits; CodeEditor counts the parameters for you.

A template error: push_back with the wrong type

A std::vector<int> holds whole numbers, and "85" in quotes is text. Errors from templates like vector are the hardest to read. For this one CodeEditor has no explanation of its own yet: it shows clang's message and marks the line.

Which C++ is this?

__cplusplus is 201703 for C++17, the default. Settings can change it.

The compiler, the library and the standard

  • clang 8.0.1 with libc++ 8, LLVM's C++ standard library, compiled to WebAssembly and run in a worker in your page. Your code is never sent to a server to be built.
  • The defaults: -std=c++17 -O2 -Wall.
  • In Settings you can choose c++11, c++14, c++17 or c++2a (clang 8's name for what became C++20, which was still being written when clang 8 was released), the optimisation level, and -Wextra.
  • Build time: building a C++ program takes a few seconds, longer than a C one; the run itself is quick. The compiler download is the same one C uses, so installing one installs both.
  • Memory: a program can use up to 256 MB.

Limits

A program stops after 15 seconds of running, or once it has printed 524,288 characters; waiting for input doesn't count, and Settings changes both. Programs read the keyboard and print text: there is no network and no window to open.

Questions

Does it work offline?

Yes, after the one-time 19.6 MB compiler download: from then on, C++ programs build and run without a connection.

Does #include <bits/stdc++.h> work?

Yes. The header belongs to GCC's library, not to libc++, but students use it so often that CodeEditor ships its own version, which includes 41 standard headers, from <algorithm> to <vector>. A program starting with it printed:

It is precompiled the first time it is used, and kept for the last few compiler settings used, so later builds that include it are faster. Code meant for other compilers is still better off including the headers it uses.

Do I need to sign up?

No. Files stay in your browser, and syncing them to your own private GitHub repository is optional.

How do I share a program?

Share it as a code link: the code travels inside the link, after #code=, a part of the address browsers never send to a server. Whoever opens it sees the code first, and nothing runs until they press Run. More on the privacy page.
